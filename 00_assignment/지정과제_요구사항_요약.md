# 지정과제 요구사항 요약

## 과제명

공공기관 사회적 책임 구매 목표 달성을 위한 환경시설 관급자재 공급망 분석 모델 개발

## 목표

환경기초시설 설치 사업의 관급자재 구매 시 사회적 책임 기업 군집과 공급망 데이터를 비교·분석하여, 한정된 품목과 예산 안에서 사회적 책임 구매 목표 달성을 지원하는 AI 기반 공급망 의사결정 모델을 개발한다.

## 요구 데이터

- 조달청 나라장터 낙찰정보서비스
- 나라장터 사용자정보서비스: 부정당제재업체정보, 조달업체 기본정보
- 공공구매종합정보망 인증서 정보 제공 서비스
- 장애인 표준사업장 조회
- 창업기업확인서 발급 기업 정보
- 자활용사촌 복지공장 생산품목
- 사회적기업 조회
- 사회적협동조합 설립현황

## 제출서류

- Python 분석 코드
- 분석 결과보고서

## 기능 요구

- 세부품명번호와 사업자등록번호 기준 분석
- 낙찰 실적, 유효기간, 지표 보유 여부, 부정당제재 반영
- 사회적 책임 지표의 공급망 밀도와 안정성 분석
- 다중지표 보유 기업 및 신뢰 가능한 후보군 식별
- 발주계획 입력에 따른 공급망 순위 출력
- AI 기법을 활용한 발주자 의사결정 지원
