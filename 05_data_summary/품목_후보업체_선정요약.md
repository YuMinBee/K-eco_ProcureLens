# 품목 및 후보업체 선정 요약

현재 수집된 `조달업체공급물품정보조회` 데이터 중 2022~2025년 데이터를 기준으로 입력 품목 10개에 대한 후보 업체를 선정했다.

후보 업체는 각 품목의 공급물품 등록 업체 중 2022~2025년 나라장터 낙찰정보에서 낙찰건수와 낙찰금액이 높은 업체를 우선으로 최대 50개씩 선정했다.

`공급물품_일치`는 점수 feature가 아니라 추천 후보에 들어오기 위한 필수 필터 조건이다.

생성 파일:

- 제출본: `04_outputs/후보업체_목록.csv`
- 원 프로젝트 실행 경로: `02_processed/후보업체_목록.csv`

주의:

- 이 파일은 실행 시점까지 수집된 조달업체공급물품정보 기준으로 생성된다.
- 현재 공유본은 2022~2025년 기준으로 재생성한 후보 업체 목록이다.
- 2026년 데이터는 월별 수집 범위가 불완전하여 공유 기준 후보 선정과 낙찰 집계에서 제외한다.
- 업체명은 조달업체 기본정보 또는 낙찰정보에서 확인된 이름을 우선 사용했다. 둘 다 없는 경우 빈칸으로 둔다.
- `대표물품`, `제조업체`는 조달업체공급물품정보조회 원천 컬럼에서 후보 생성 시 자동 산출한다.
