# 데이터 출처 및 처리 요약

## 활용 데이터

| 데이터 | 제출본 내 역할 |
|---|---|
| 조달청 나라장터 낙찰정보서비스 물품 | 낙찰건수, 최근낙찰건수, 낙찰금액합계, 평균낙찰금액, 모델 학습 label 생성 |
| 조달업체 공급물품정보조회 | 세부품명번호별 공급 가능 업체 후보군 생성 |
| 조달업체 기본정보조회 | 업체명, 대표자명, 주소 보강 |
| 부정당제재업체정보조회 | 제재 이력과 현재 제재 여부 반영 |
| 창업기업확인서 발급 기업 정보 | 창업기업 지표 |
| 장애인 표준사업장 실시간 조회 | 장애인표준사업장 지표 |
| 공공구매종합정보망 인증서 정보 | 공공구매 인증 지표 |
| 국가보훈부 자활용사촌 복지공장 생산품목 | 자활용사촌 복지공장 및 생산품목 매칭 |
| 사회적기업 조회 | 사회적기업 지표 |
| 사회적협동조합 설립현황 | 사회적협동조합 지표 |

일부 정책인증 API는 호출 제한 또는 후보군 내 확정 매칭 부족으로 인해 미매칭 또는 보수적 0값으로 처리하였다. 따라서 정책성 지표는 확정 매칭된 창업기업, 장애인표준사업장, 사회적기업 등 확인 가능한 지표를 중심으로 해석한다.

## 처리 흐름

1. 발주 대상 세부품명번호를 기준으로 공급물품 등록 업체 후보를 생성한다.
2. 후보 업체를 사업자등록번호 기준으로 낙찰, 제재, 정책인증, 사회적 가치 데이터와 결합한다.
3. 과거 낙찰 이벤트로 학습한 AI 랭킹 모델을 기준으로 후보별 AI 예측점수를 산출한다. 학습 데이터가 갱신되면 재학습하고, 단순 후보 갱신은 저장 모델 예측으로 처리한다.
4. 규칙기반 프리셋 4종을 별도 해석 기준으로 계산한다.
5. 대시보드에서 AI 순위와 프리셋 해석, 지표 기반 후보군을 함께 확인한다.
