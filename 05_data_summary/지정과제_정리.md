# 지정분석 과제 정리

## 과제 개요

- 과제명: 공공기관 사회적 책임 구매 목표 달성을 위한 환경시설 관급자재 공급망 분석 모델 개발
- 담당 부서: 부울경환경본부 환경시설관리처 시설사업부
- 분석 도구: Python

환경기초시설, 소각, 하수처리, 바이오 등 설치 사업의 관급자재 구매 시 사회적 책임 기업 데이터를 비교 분석하여 사회적 책임 구매 목표 달성을 지원하는 공급망 의사결정 모델을 개발한다.

## 공개 데이터 목록

| 번호 | 데이터/API | 유형 | 포맷 | 주요 내용 |
|---:|---|---|---|---|
| 1 | 조달청_나라장터 낙찰정보서비스 | Open API | REST, JSON/XML | 검색조건에 의한 물품 낙찰 목록, 사업자번호 등 |
| 2 | 나라장터 사용자정보서비스 | Open API | REST, JSON/XML | 부정당제재업체정보, 조달업체 기본정보 등 |
| 3 | 공공구매종합정보망 인증서 정보 제공 서비스 | Open API | REST, XML | 직접생산확인, 여성기업확인, 장애인기업확인 등 |
| 4 | 장애인 표준사업장 실시간 조회 | Open API | REST, XML | 장애인 표준사업장 정보 |
| 5 | 창업기업확인서발급기업정보 조회서비스 | Open API | REST, JSON/XML | 창업기업확인서 발급 기업 정보 |
| 6 | 자활용사촌 복지공장 생산품목 | 파일 데이터 | CSV | 자활용사촌 복지공장 생산품목 |
| 7 | 사회적기업 조회 | 파일 데이터 | XLSX | 사회적기업 포털 자료 |
| 8 | 사회적협동조합 설립현황 | 파일 데이터 | XLSX | 한국사회적기업진흥원 사회적협동조합 자료 |

## 제출 산출물

- 분석 코드: Python
- 분석 결과보고서

## 활용 계획

- 분석 엔진을 내재화하여 발주 실무 의사결정 지원형 리포트로 활용한다.
- 기관 내 환경기초시설 설치 사업에서 사회적 가치 실현 사례로 활용한다.

## 분석 방향

- 나라장터 낙찰정보를 기반으로 공급망 변동성, 낙찰 실적, 인증 유효기간, 지표 보유 여부 등을 반영한다.
- 세부품명번호와 사업자등록번호를 주요 키로 사용한다.
- 사회적 책임 기업 지표, 공급망 밀도, 공급망 안정성, 다중지표 보유 여부, 낙찰 실적, 부정당제재 여부 등을 비교 분석한다.
- 실무자가 신뢰 가능한 공급망 그룹을 식별할 수 있도록 대시보드 또는 추천 순위를 구성한다.

## 데이터 레이아웃 예시

입력:

- 발주계획
- 세부품명번호
- 추정금액
- 추가 입력 항목

출력:

- 공급망 순위
- 순위
- 업체명
- 사업자번호
- 대표자명
- 주소
- 지표합
- 지표명 또는 Y/N 여부

## 현재 프로젝트 반영 방식

- 품목 선정: `조달업체공급물품정보조회`의 `세부품명번호`, `세부품명`
- 후보 업체 생성: 품목별 공급 가능 업체의 `사업자번호`, `업체명`
- feature 병합: 팀원별 산출 feature를 `사업자번호` 기준으로 병합
- 점수 계산: 균형형, 안정성 중심, 사회적 가치 중심, 위험 회피 중심 프리셋 적용
