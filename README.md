# 공공기관 사회적 책임 구매 목표 달성 공급망 분석 모델 제출본

## 심사위원 1분 확인 방법

1. `02_dashboard/procurement_decision_dashboard.html`을 브라우저에서 연다.
2. 기본값 `4710160801` 유기응집제를 그대로 확인하거나, 세부품명번호에 `4015150501` 정량펌프 또는 `4015151301` 수중펌프를 입력한다.
3. 기본 추정금액과 `균형형` 프리셋을 그대로 두어도 AI 추천 Top 5, 예산 적합성, 사회적 책임 지표, 제재 여부를 한 화면에서 비교할 수 있다.
4. 담당자는 이 화면을 기준으로 후보업체 우선순위와 검토 사유를 확인할 수 있다.

## 구성

- `00_assignment/`: 지정과제 요구사항 요약
- `01_report/`: 최종 PDF 보고서, 분석 결과 요약, 요구사항 대응표, 실행 방법
- `02_dashboard/`: 발주 실무 의사결정 지원 대시보드 HTML
- `03_code/`: Python 분석 코드
- `04_outputs/`: 후보 목록, AI 예측 결과, 프리셋 점수, 성능 지표
- `05_data_summary/`: 활용 데이터 출처 및 처리 요약
- `심사위원_1분_확인가이드.md`: 바로 확인할 파일과 업무 흐름 요약

## 핵심 산출물

- 심사위원 1분 확인가이드: `심사위원_1분_확인가이드.md`
- 최종 분석 결과보고서 PDF: `01_report/05_18_사회적책임구매_공급망분석.pdf`
- 분석 결과 요약: `01_report/분석_결과보고서.md`
- 요구사항 대응표: `01_report/요구사항_대응표.md`
- 대시보드: `02_dashboard/procurement_decision_dashboard.html`
- 실행 파이프라인: `03_code/run_procurement_dashboard_pipeline.py`
- 저장 모델 예측: `03_code/score_hgb_supplier_candidates.py`

참고: `04_outputs/`는 제출본에 포함된 확인용 산출물이며, 파이프라인 재실행 시 새 산출물은 `02_processed/`에 생성된다.

`score_hgb_supplier_candidates.py`는 전체 파이프라인 실행 중 `02_processed/후보업체_목록.csv`와 표준화 데이터가 생성된 이후 실행되는 내부 예측 단계이다. 제출본에서 결과만 확인할 경우 `04_outputs/model_outputs/HGB_후보업체_AI예측점수.csv`를 확인하면 된다.

## 현재 제출본 기준

- 적용 품목: 유기응집제, 기타수질분석기, 여과장치, 무기응집제, 수처리용여과재, 정량펌프, 송풍기, 유량계, 수중펌프, 제수밸브
- 후보 업체: 품목별 50개, 총 500개
- AI 엔진: HistGradientBoosting 기반 후보업체 랭킹 모델
- AI 실행 방식: 학습 데이터가 갱신되면 HGB 재학습, 단순 후보 갱신은 저장 모델로 예측
- 프리셋 해석: 균형형, 안정성 중심, 사회적 가치 중심, 위험 회피 중심
- 갱신 방식: 신규 품목 누적 목록 기반 파이프라인 재생성, 예약 갱신 스크립트 제공
