# 분석 결과보고서

## 1. 분석 목적

본 프로젝트는 환경기초시설 관급자재 구매 시 사회적 책임 구매 목표를 달성할 수 있도록, 세부품명번호와 사업자등록번호를 기준으로 공급 가능 업체를 식별하고 AI 기반 우선순위와 지표 기반 해석을 제공하는 공급망 의사결정 모델을 구축했다.

## 2. 분석 범위

현재 제출본은 대표 환경시설 관급자재 10개 품목을 대상으로 품목별 50개 후보, 총 500개 후보 업체를 구성했다.

| 세부품명번호 | 품목명 | 후보 수 |
|---:|---|---:|
| 4710160801 | 유기응집제 | 50 |
| 4111331901 | 기타수질분석기 | 50 |
| 4016150601 | 여과장치 | 50 |
| 4710160802 | 무기응집제 | 50 |
| 4710169801 | 수처리용여과재 | 50 |
| 4015150501 | 정량펌프 | 50 |
| 4010160101 | 송풍기 | 50 |

신규 품목은 `run_procurement_dashboard_pipeline.py --item 세부품명번호:물품명`으로 추가하며, 입력 물품은 `대시보드_물품목록.csv`에 누적된다.

## 3. 데이터 구성

주요 키는 다음과 같다.

- 품목 키: 세부품명번호 10자리
- 업체 키: 사업자등록번호 정규화 값
- 후보 키: 세부품명번호와 사업자등록번호 조합

활용 데이터는 나라장터 낙찰정보, 조달업체 공급물품정보, 조달업체 기본정보, 부정당제재 정보, 창업기업/장애인표준사업장/공공구매인증/사회적기업/사회적협동조합/자활용사촌 복지공장 데이터다.

일부 정책인증 API는 호출 제한 또는 후보군 내 확정 매칭 부족으로 인해 미매칭 또는 보수적 0값으로 처리하였다. 따라서 정책성 지표는 확정 매칭된 창업기업, 장애인표준사업장, 사회적기업 등 확인 가능한 지표를 중심으로 해석한다.

## 4. 모델 구조

### 후보 생성

세부품명번호별 공급물품 등록 업체를 수집하고, 2022년부터 2025년까지의 낙찰 실적을 기준으로 품목별 상위 후보를 구성했다.

### AI 랭킹 모델

AI 모델은 후보 생성 이후 후보 업체 간 우선순위를 예측한다. 모델은 과거 낙찰 이벤트에서 실제 낙찰업체를 positive label로, 같은 품목의 공급 가능 업체를 negative 후보로 구성해 학습했다.

운영/갱신 단계에서는 저장된 HGB 모델을 불러와 신규 후보업체를 예측한다. 다만 표준화된 낙찰/공급물품/제재/사회책임 데이터가 저장 모델보다 최신이면 자동 재학습하고, 단순 신규 물품 추가처럼 학습 데이터 자체가 바뀌지 않은 경우에는 예측만 수행한다.

사용 feature 예시는 다음과 같다.

- 대표물품 여부
- 제조업체 여부
- 공급품목 등록 후 경과일수
- 업체 등록품목 수
- 품목 공급업체 수
- 이전 전체 낙찰건수
- 이전 동일/대분류 낙찰건수
- 최근 365일 낙찰건수
- 이전 낙찰금액합계
- 참가업체 수
- 창업기업, 장애인표준사업장, 사회적기업
- 부정당제재

### 프리셋 해석

AI 순위는 주 추천 결과이며, 프리셋은 실무자가 AI 결과를 해석하는 관점으로 사용한다.

- 균형형
- 안정성 중심
- 사회적 가치 중심
- 위험 회피 중심

## 5. 성능 결과

최종 모델 비교 결과는 HistGradientBoosting이 가장 높은 랭킹 성능을 보였다. 아래 표에서 Hit@n은 퍼센트(%) 단위이고, MRR은 0~1 범위의 평균 역순위 점수다.

| 모델 | Hit@1(%) | Hit@3(%) | Hit@5(%) | MRR |
|---|---:|---:|---:|---:|
| HistGradientBoosting | 58.68 | 77.54 | 85.18 | 0.7040 |
| RandomForest | 57.28 | 76.49 | 83.77 | 0.6923 |
| ExtraTrees | 54.65 | 73.42 | 81.75 | 0.6675 |
| 규칙기반 균형형 | 28.48 | 49.00 | 60.70 | 0.4372 |

현재 제출본은 학습 완료된 HGB 모델을 저장해 두었고, 후보 500개에 대한 AI 점수와 프리셋 점수를 산출했다.

## 6. 대시보드 기능

대시보드는 발주 실무자가 다음 흐름으로 사용할 수 있도록 구성했다.

1. 발주계획 입력: 세부품명번호, 추정금액, 사업자번호 선택 입력, 해석 프리셋
2. AI Top 5 프리셋 해석: AI 상위 후보를 선택 프리셋 관점으로 재해석
3. 프리셋 Top 5 순위: 선택 프리셋 기준 상위 업체 확인
4. 공급망 순위: 업체명, 사업자번호, 대표자명, 주소, 사회책임 지표, 낙찰/제재 지표 확인
5. 지표 기반 후보군 탐색: 다중지표 보유, 낙찰건수 상위, 낙찰금액 상위, 부정당제재, 예산 적합 그룹 확인

다중지표 보유는 사회책임, 낙찰건수, 예산적합, 제재없음, 제조업체 중 2개 이상을 충족하는 후보로 정의했다.

## 7. 자동 갱신 구조

완전한 실시간 조회는 데이터량과 API 호출 제한 때문에 비효율적이므로, 제출본은 주기적 자동 갱신 방식으로 설계했다.

- `run_procurement_dashboard_pipeline.py`: 후보 생성부터 대시보드 재생성까지 일괄 실행
- `score_hgb_supplier_candidates.py`: 저장된 HGB 모델로 현재 후보업체만 예측
- `schedule_procurement_updates.py`: 일정 시간마다 파이프라인 실행
- `pipeline_status.json`: 마지막 갱신 상태 기록

따라서 보고 표현은 `공공 API 및 수집 데이터를 주기적으로 자동 갱신하여 최신 공급망 변동성을 대시보드에 반영`으로 정리하는 것이 적절하다.

## 8. 정책 활용 및 리스크 관리

본 모델은 공공조달 담당자가 물품별 후보업체, 사회적 책임 지표, 낙찰 실적, 제재 위험을 한 화면에서 비교하도록 돕는 1차 검토 지원 도구다. 기존에 담당자가 개별적으로 확인하던 후보 탐색, 인증 여부 확인, 제재 여부 확인 과정을 대시보드에서 함께 제공해 반복적인 자료 확인 시간을 줄이고 조달 검토의 투명성을 높이는 데 목적이 있다.

다만 AI 추천 결과가 최종 계약 결정을 자동으로 대체하는 것은 아니다. 실제 계약 전에는 원천 데이터와 공식 등록 정보를 재확인하고, 담당자가 선택한 프리셋과 주요 검토 사유를 함께 기록하는 방식으로 운영하는 것이 적절하다.

## 9. 결론

본 제출본은 지정과제에서 요구한 Python 분석 코드, 분석 결과보고서, 사회적 책임 지표 기반 공급망 비교, AI 기반 의사결정 모델, 발주계획 입력형 대시보드를 모두 포함한다. 모델 결과는 규칙기반 프리셋보다 높은 랭킹 성능을 보이며, 실무자는 AI 순위를 기본 추천으로 보고 프리셋과 지표 후보군을 통해 의사결정 사유를 확인할 수 있다.

## 10. 한계 및 유의사항
