## 유의사항

- 제출본은 정적 HTML 대시보드이므로 신규 품목은 파이프라인 실행 또는 예약 갱신 이후 반영된다.
- 공공 API는 호출량과 인증키 제약이 있어 최종 제출본에는 표준화된 로컬 데이터와 API 호출 옵션을 함께 제공한다.
- 모델은 실제 입찰 참여자 전체 명단이 아니라 공급 가능 업체 후보군 내부의 우선순위 예측 모델로 해석해야 한다.
